任务首次响应时长

P01 · 分钟/工作小时
确认接收时间−正式分派时间

来源：飞书任务 + 接收事件

节点按时验收率

P02 · %
按期验收的节点数÷期间到期节点数

来源：节点计划 + 验收 + 批准变更

eval · 怎样验证有效

  • 数据校验：抽查节点是否漏记、错配订单；交期与改期是否有依据。
  • 业务评估：按同类节点比较响应、按时验收和上游等待，分别看执行与等待。

员工考评 · 可用证据

  • 是否及时确认承接、回填阻塞和按约交付
  • 有效改期、外部等待、主管验收均可追溯

绩效约束 · 先说明条件

  • 群消息已发 / 已读，不等于接单
  • 缺料和工厂延期不能直接记成跟单个人失职
跨部门交接采购回填物料承诺 → 生产协调 → 仓库回填实到；HR接收经复核的履职记录。
预警条件节点超出已确认期限→通知 / 承接承接人 / 生产负责人→建议动作核查缺料、依赖与改期，再协调执行

完整指标口径

指标公式边界
任务首次响应时长正式分派至确认接收的时长；未接收事项单列。群消息发出或已读不能代替正式接单；明确非工作时段规则。
节点按时验收率按期验收事项数 / 期间应到期事项数；有效改期与暂停单列。先确认计时规则；不把外部阻塞直接计为个人违约。

抽检不合格件比例

Q01 · %
样本中不合格件数÷实际检验样本件数

来源：QC记录 + 检验方式；不代替整批次品率

整改按期复核率

Q02 · %
按期复核通过的整改数÷到期整改事项数

来源：整改任务 + QA复检

eval · 怎样验证有效

  • 数据校验：重算样本数与不合格件，检查照片、批次及复检关联。
  • 业务评估：按同检验方式、品类与工厂比较；评级看质量、复发、整改时效等维度。

员工考评 · 可用证据

  • 检验是否按要求执行、记录是否完整
  • 异常是否上报，整改与复检是否按职责闭环

绩效约束 · 先说明条件

  • 抽检不合格比例不等于整批真实次品率
  • 工厂质量差，不直接等于QC员工失职；不以少报问题换低次品率
跨部门交接采购 / 工厂提供批次 → QC检验 → 工厂整改 → QA放行 → 仓库接收。
预警条件达到批准质量红线 / 整改超期→通知 / 承接QA / 质量负责人→建议动作核实批次证据，按授权决定隔离、整改与放行

完整指标口径

指标公式边界
抽检不合格件比例本次不合格件数 / 本次实际检验件数。不合格件与缺陷次数分开；不把样本比例直接当整批真实次品率。
整改按期复核率按期复核完成的整改项 / 应到期整改项。提交照片不自动等于复检通过；同一缺陷复发另留关联。

AI辅助的验收方式

AI可归类缺陷、汇总工厂问题；对照人工复核样本评估错分、漏报、证据引用。红线与放行由授权质量人员确认。

本部门会审要确认

确认抽检方案、红线、放行权限、工厂对应关系与评级规则；A/B/C暂不自动打分。
